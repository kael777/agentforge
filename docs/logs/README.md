# 开发日志

记录**做过什么、为什么这么做、踩了什么坑**。

和 `docs/plans/` 的区别：

| 目录 | 是什么 | 是否入库 |
|---|---|---|
| `docs/plans/` | 可执行手册：前置、命令、验收、回滚 | ❌ 含真实拓扑，本地维护 |
| `docs/logs/` | 事后记录：决策、坑、结果 | ✅ 已脱敏，随仓库发布 |

## 脱敏规则

日志里不出现：公网 IP、内网地址分配、公钥/私钥、办公网出口 IP、账号密码。
需要指代时用 `基建`、`应用 A`、`应用 B`。
